# DKIST_SolO_Fibril
---

This repository contains the code used to analyze and generate the figures and movies in the paper "Active Region fibrils and their hotter counterparts" by Zhu et al. (2026), submitted to A&A. The figures are presented in the order they appear in the paper, with each figure's corresponding Jupyter notebook provided for reproducibility.

[Figure 1](https://yjzhu-solar.github.io/DKIST_SolO_Fibril/ipynb_html/fov_summary.html) shows the fields of view of VBI, ViSP, and IRIS/SJI overplotted on context images or magnetograms from SDO/AIA, EUI/FSI, SDO/HMI, and PHI/HRT.

[Figure 2](https://yjzhu-solar.github.io/DKIST_SolO_Fibril/ipynb_html/all_channel_layout.html) presents the multi-wavelength observations of the chromospheric fibrils and their hotter counterparts, including DKIST/VBI, SolO/EUI HRIEUV, SDO/AIA, and IRIS/SJI. The animated version of this figure is generated in [Online Movie 1](https://yjzhu-solar.github.io/DKIST_SolO_Fibril/ipynb_html/all_channel_layout_movie.html).
